# PlutoSDR Exhaustive Search

Our Final Project for COSMOS. Exhaustively searches through every combination of Compression, Recovery, Constellation, and Repetition parameters, testing them on different file types. Analyzes transmission/encoding times and error rates. Automatically plots information for analysis.

## Features

- Compression Algorithms
 - Huffman
 - Lempel-Ziv 
- Recovery Algorithms
 - Repetition
 - Hamming
 - Reed-Soloman
- Constellation Size
 - 2
 - 4
 - 8
 - 16
- Repitition Sizes
 - 2
 - 4
 - 6
 - 8
- Auto-Analysis

## Getting Started

Follow these instructions to set up and run the project on your local machine.

### Prerequisites

This package uses an Anaconda environment. Please install this environment to use the library.

### Installation

1. Clone the repository:

```bash
git clone https://github.com/HeckerWithAHat/PlutoSDR-Exhaustive-Search.git
cd PlutoSDR-Exhaustive-Search
```

2. Start the program:

```bash
python main.py
```
